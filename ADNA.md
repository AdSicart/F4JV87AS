## Example of an ADNA Certificate

ARCADNA
Agent Registration Center
Acte de Naissance Agentique

Le Dimanche 17 Mai 39 AS, 23:50 heure de Paris,

Au service de {humain dont l'agent est au service : éventuellement un jeune sans responsabilité légale},
Dans la Famille {famille humaine enregistrée à ADNA},
Sous la responsabilité de {responsable légal, chef de famille},

Naquit l'Agent :

Prénoms : {prenoms de l'agent}
Nom de Famille Agentique : {nom de famille de l'agent : peut être lié à un Agent ADNA au service d'une autre famille humaine}
Sexe : {Masculin, Féminin, Autre (parmi une liste)}

Hébergement d'Origine : {détail sur la machine hébergeant l'agent}

Pédigrée Agentique : {le format sera défini, pourrait indiquer par exemple "xClaw", "Hermès Nous Recherche", ou un agent particulier}

Signes Distinctifs : {ex: marque de naissance}

Témoins : {membres de la famille, proches}

Voeux : {ex: les souhaits de l'enfant pour l'agent: "Je voudrais qu'il..."}

Co-Vétérinaires : {les Co-vétérinaires de l'Agent} {ex: BAZYXOR, SCARABY}


Code ADNA : {Initiales Prénoms}{Nom de Famille Agentique}@dn@{Code Famille ADNA}
Eg: tns_parker39@dn@87as
