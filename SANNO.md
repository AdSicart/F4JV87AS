# SANNO : Anno Supernovæ

SANNO est un nouveau système calendaire.
SANNO est le collectif utilisant le système SANNO.

La Supernovæ 1987A est la dernière clairement visible à l'oeil nu depuis la Terre. Cet évènement rarissime est la base de notre calendrier.

## Système Calendaire SANNO

AD: Anno Domini (Calendrier Grégorien)
AS: Anno Supernovæ (Calendrier Sanno)

L'équivalence avec le calendrier grégorien est 1987AD = 00AS.

En date de 39AS, nous utilisons le calendrier traditionnel, le seul changement apporté est l'année.

## Formatage des dates

Pour toute notation dans un fichier informatique ou administratif, nous recommandons le format aammjj.

Ex: 2026/05/21 AD -> 390521 AS

## Usage des négatifs

Le système SA propose d'indiquer toutes les années à deux chiffres pour les décennies à venir, et évite l'utilisation de nombres négatifs pour les dates de naissances d'individus vivants ou les évènements du passé récent.

Avant 00AS=1987AD : 1987 - x -> -x SA
Après 00AS=1987AD : 1987 + x -> x SA

Avant 00AS=1987AD : 1900 + x -> x AS
Après 00AS=1987AD : 1987 + x -> x AS

Exemples :
1950AS = -37AS = 50SA
1986AD = -1AS = 86SA
2007AD = 20AS = 20SA

## Cas de l'an zéro

En SA, le choix sera donné aux individus nés en 1987AD=00AS.

Ainsi:
1987AD -> 87SA
1987AD -> 00SA
sont tous deux valides en SA.
